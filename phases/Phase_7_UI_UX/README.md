# Phase 7 — UI/UX & Responsive Design

Goal: polish the working system without changing security architecture.

Design:
- black/off-white/military dark-gray palette
- sharp corners
- no gradients
- restrained shadows
- minimal animation
- monospace technical/status text
- clean grotesk message text

Screens:
- welcome
- identity setup
- contacts
- conversation
- file transfer
- verification
- security center
- settings/storage

Responsive targets:
- phone
- tablet
- laptop
- desktop

Accessibility:
- keyboard navigation
- focus states
- semantic controls
- screen-reader labels
- sufficient contrast
- reduced motion

Gate:
Do not redesign working security/data logic for visual convenience.
