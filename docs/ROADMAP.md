# Roadmap

## Phase 0
Repository inspection, feasibility and crypto/dependency research.

## Phase 1
Architecture, data model, API/WebSocket contracts and threat model.

## Phase 2
Browser cryptographic proof of concept.

## Phase 3
Identity and key management.

## Phase 4
Secure 1-to-1 messaging.

## Phase 5
Encrypted file sharing.

## Phase 6
Safety-number/QR verification and security hardening.

## Phase 7
UI/UX polish, accessibility and responsive behavior.

## Phase 8
Cross-browser, security and end-to-end testing.

## Phase 9
Cloudflare deployment and production verification.

## Phase 10
Documentation and release.

## V1 non-goals
No calls, groups, social feed, stories, AI, ads, plaintext backup, server-side plaintext search, onion routing, payments, phone/email authentication.
