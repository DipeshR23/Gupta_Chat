# Limitations and Honest Claims

## Known limitations
- Browser storage has quotas.
- Private/incognito browsing can behave differently.
- iOS browsers have platform-specific restrictions.
- Background tabs may be suspended.
- A compromised device can expose plaintext.
- Browser extensions may observe or alter a page.
- Screenshots and recording cannot be reliably prevented.
- E2EE does not automatically hide all metadata.
- Free hosting tiers have quotas and can change.
- File size and memory constraints depend on browser/device.
- Cross-browser support requires continuous testing.

## Claims
Do say:
- end-to-end encrypted messaging
- client-side encrypted files
- server does not need plaintext content
- cryptographic identity verification

Do not say:
- 100% secure
- unhackable
- anonymous
- zero metadata
- screenshot-proof
- malware-proof
