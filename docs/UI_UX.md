# UI/UX Specification

## Design identity
- black
- off-white
- military dark-gray
- sharp corners
- no gradients
- minimal shadows
- restrained animation
- monospace for technical/status text
- clean grotesk for message body

## Screens
1. Welcome
2. Identity setup
3. Contacts
4. Conversation
5. File transfer
6. Verification
7. Security center
8. Settings/storage management

## Chat
Desktop uses contact list + conversation panel.
Mobile uses navigation from contacts to conversation.

## Message status
Sending, sent, delivered, read, failed.

## File card
Show type, filename, size, progress, encryption/decryption state and action.

## Security center
Show identity, verification, encryption state, local storage usage, clear cache, delete all local data and threat-model explanation.

## Accessibility
- keyboard navigation
- focus indicators
- sufficient contrast
- semantic controls
- screen-reader labels
- reduced motion

## Responsive
Target mobile, tablet, laptop and desktop.
Test Chrome, Edge, Firefox, Safari; Android Chrome; iOS Safari/PWA.
