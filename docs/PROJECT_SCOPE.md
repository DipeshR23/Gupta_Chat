# Project Scope Summary

## Build
A web-only, security-first 1-to-1 messaging and encrypted file-sharing system.

## Main features
- username identity
- client-side cryptographic identity
- secure 1-to-1 messaging
- disappearing messages
- delivery/read status
- encrypted images/files/videos/documents
- safety-number/QR verification
- encrypted local storage
- local storage cleanup
- responsive UI
- Cloudflare hosting architecture

## Do not build in V1
Voice/video calls, groups, stories, social features, AI, ads, phone/email login, plaintext cloud backup, server-side plaintext search, onion routing and payments.

## Core priority
Security -> correctness -> privacy -> reliability -> compatibility -> performance -> UX -> visual polish.
